### Selected Work

**Study_Buddy — Multi-Agent AI System**

A multi-agent educational system designed to deliver personalized mathematical explanations by combining knowledge retrieval with conversational AI.

- **Theory Agent:** Retrieves relevant mathematical knowledge from a large theory repository.
- **Creative Agent:** Turns retrieved knowledge into clear, conversational explanations.
- **Cloud AI:** Built using Google Cloud AI technologies.

The project explored how specialized agents can work together to make AI-generated answers more grounded and useful.
